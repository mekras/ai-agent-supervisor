# Подключение и настройка Hermes

Выберите область работы:

- [Личный помощник Hermes](#личный-помощник-hermes) — общие правила выбранного
  профиля. Готовый проект не требуется.
- [Отдельный проект](#подключение-к-отдельному-проекту) — инструкции и навыки
  для работы с конкретным каталогом в Hermes.

## Личный помощник Hermes

### Подключите коллекцию

В существующем диалоге с Hermes попросите:

> Установи себе коллекцию навыков https://github.com/mekras/ai-agent-supervisor версии 2.6.31 через APM в свой текущий профиль Hermes. Покажи имя профиля и его каталог. Проверь, что можешь обнаружить и открыть навык ai-setup-project. Сообщи, если какие-то проверки не прошли.

Установка делает навыки доступными в выбранном профиле. После проверки
обнаружения и открытия навыка переходите к настройке. Если проверка не прошла,
передайте Hermes сообщение об ошибке и попросите объяснить, что мешает продолжить.

### Настройте помощника

Продолжите в том же профиле:

> Выполни ai-setup-project. Настрой себя как личного помощника в текущем профиле Hermes. Готового проекта у меня нет. Покажи, где будут храниться настройки и на какие разговоры и задачи они повлияют. Объясняй изменения простыми словами и показывай последствия для моей работы, доступа к данным и расходов.

Настраивается каталог выбранного профиля Hermes. Его фактический путь покажет
помощник. Для профиля по умолчанию это обычно `~/.hermes`, но у других профилей
он отличается. Переходить в этот каталог или создавать Git-репозиторий для
личной настройки не требуется.

Общие инструкции общения и работы помощника сохраняются в профиле и действуют
в его разговорах. Рабочий каталог нужен отдельно для документов и конкретных
поручений. Правила такого каталога относятся к этой работе. Настройка профиля
сама по себе не ограничивает доступ помощника к файлам. Это разные области
[настроек Hermes](https://hermes-agent.nousresearch.com/docs/user-guide/profiles/#profiles-vs-workspaces-vs-sandboxing).

Перед сохранением каждого изменения проверьте предложенные файлы и область
действия. Подтверждайте только подходящие изменения. Доступ к новым данным,
внешние действия и новые расходы согласуются отдельно. Если Hermes не может
получить одобрение защищённой записи, он покажет подготовленную правку и способ
применить её самостоятельно.

### Проверьте сохранение настроек

После сохранения откройте новый разговор в том же профиле и попросите:

> Проверь, что загружены согласованные инструкции моего профиля. Покажи, откуда они загружены, и примени согласованное правило общения в ответе.

При доступной команде `/context` можно посмотреть загруженные файлы.
Инструкции профиля и проектного каталога загружаются по
[разным правилам Hermes](https://hermes-agent.nousresearch.com/docs/user-guide/features/context-files/).
Если нужный файл не загружен, передайте помощнику результат проверки.
До устранения причины настройка остаётся непроверенной.

## Подключение к отдельному проекту

Для установки потребуется [APM](https://microsoft.github.io/apm/) не ниже 0.29.1.

Подключите реестр коллекции:

```bash
apm marketplace add mekras/apm-marketplace --ref master
```

Выполните в корне Git-репозитория проекта:

```bash
apm install ai-agent-supervisor@mekras#2.6.31 --target hermes
```

Чтобы Hermes загружал навыки этого проекта, предоставьте ему доверие.
Это разрешит загрузку местных инструкций навыков. Выполните в том же каталоге:

```bash
hermes skills trust .
hermes skills list --source local
```

Первая команда сохраняет этот проект в списке доверенных в настройках Hermes.
Убедитесь, что в списке навыков есть `ai-setup-project`. Затем откройте Hermes
в этом проекте и попросите проверить, что он может открыть навык. Если навык
недоступен, передайте агенту вывод команд и укажите каталог, из которого они
запускались. После проверки доступности переходите к настройке ниже.

Подробнее о доверии — в [руководстве Hermes, разделе «Trusting a project»](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/user-guide/features/skills.md#trusting-a-project).

### Настройте проект

Откройте в агенте тот каталог проекта, в который установили коллекцию,
и попросите:

> Настрой этот проект для работы с агентами. Выполни ai-setup-project.

Настройка относится к выбранному проекту. Общие настройки профиля помощника
имеют отдельную область и требуют отдельного согласования.

## Границы проведённых проверок

Установка и обнаружение локальных навыков Hermes проверены отдельно от работы
навыков в среде агента. Правка `AGENTS.md` в Hermes Agent проверена только
на локальном кандидате. Маршрут Hermes → Codex с записью приёмки проверен
отдельно на одном учебном проекте локального
кандидата. Настройка с нуля, личная настройка с проверкой в новом разговоре
и экономия не проверены в живом Hermes.
