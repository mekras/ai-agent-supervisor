# DR-0008. Разделение проектных инструкций и источников знаний

## Контекст

Главный технический принцип проекта — управление сложностью. Подробности
запуска подагентов постоянно занимали корневой контекст, а оперативная политика
содержала историю настройки и повторяющиеся обоснования. Указатель на концепцию
вёл на README, который её не закреплял. Правила корпуса смешивали источник
знаний с обязательным основанием и ограничивали его применение продуктом.

## Рассмотренные варианты

Сохранение всей процедуры и истории в постоянно читаемых материалах оставляет
лишнюю нагрузку на контекст. Для разделения выбран вариант с кратким корневым
входом, проектной процедурой по требованию и локальным историческим снимком.

Концепция оформляется отдельным документом. Ограничение корпуса только
публикуемыми навыками отвергнуто: его знания могут быть полезны и для проекта.

## Решение

Концепция находится в [отдельном документе](../concept.md). README содержит
ссылку для человека, а корневые инструкции и проектный запускатель указывают
на этот документ.

Корневые инструкции сохраняют ранний выбор маршрута, границы полномочий и
проверку допуска. Подробности передачи и приёмки находятся в
[проектной процедуре](../agent-work/subagents.md). Оперативная политика
содержит рабочие условия и ссылку на локальную историю квалификации.

Корпус — источник знаний для продукта и проекта. Его сведения оцениваются по
происхождению, достоверности, актуальности и применимости. Сами по себе они не
устанавливают требования, правила или принятые решения.

## Последствия и проверка

Разделение сокращает постоянно читаемые материалы, сохраняя исходные
ограничения. Изменение размещения не квалифицирует маршруты подагентов и не
разрешает новые модельные эксперименты.

Проверка сопоставляет прежние ограничения с новыми местами, подтверждает
доступность ссылок и загрузку концепции запускателем без вызова модели.
Миграция шаблонных инструкций должна сохранять проектное разделение.
Если реальное применение выявит потерю обязательного шага, порядок загрузки
нужно пересмотреть. Уменьшение объёма текста само по себе не доказывает экономию.
