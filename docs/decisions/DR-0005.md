# DR-0005: Публикация коллекции через общий реестр APM

**Статус:** принято 2026-09-01

## Контекст

Коллекция устанавливалась из ссылки на исходный репозиторий. Пользователю
приходилось передавать одновременно адрес репозитория, диапазон версии и цель
установки. APM поддерживает общие реестры пакетов: один репозиторий публикует
каталог, а проекты-потребители подключают его и устанавливают пакет по
устойчивому имени.

Владелец проекта поручил перевести публикацию коллекции на общий реестр APM по
модели `ai-russian-language`. Изменение затрагивает способ обнаружения и
установки коллекции, но не состав публикуемых навыков.

## Рассмотренные варианты

### 1. Сохранить установку напрямую из репозитория

Вариант не требует метаданных реестра, но оставляет пользователю составление
ссылки на репозиторий и диапазона версии.

### 2. Публиковать пакет через общий реестр APM

Вариант публикует пакет в `mekras/apm-marketplace`. Выпуск исходного
репозитория по тегу проверяет коллекцию, переносит её публичный состав в общий
реестр и пересобирает описания для Claude и Codex. Потребитель один раз
подключает общий реестр, после чего устанавливает и обновляет коллекцию
обычными командами APM.

## Решение

Принят вариант 2. Пакет `ai-agent-supervisor` публикуется через
`mekras/apm-marketplace`. Версия исходного тега совпадает с версией пакета.
Общий реестр хранит сгенерированные описания для Claude и Codex.

## Последствия

- Установка начинается с `apm marketplace add mekras/apm-marketplace`.
- Пакет устанавливается по имени `ai-agent-supervisor@mekras`.
- Перед выпуском необходимо обновить версию, журнал изменений и создать тег
  исходного репозитория.
- Для автоматического выпуска нужен секрет `APM_MARKETPLACE_TOKEN` с доступом
  на запись только к `mekras/apm-marketplace`.

## Проверка и условия пересмотра

Проверка включает `apm run tests` в исходном репозитории, `apm marketplace
check`, сборку реестра командой `apm pack` и проверку отсутствия дрейфа с
`apm pack --check-clean --dry-run` в общем реестре.

Решение следует пересмотреть, если APM изменит формат реестра, прекратит
поддержку выходов для Claude или Codex либо появится обязательный для целевой
аудитории другой способ распространения.
