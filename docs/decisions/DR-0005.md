# DR-0005: Публикация коллекции через реестр APM

**Статус:** принято 2026-09-01

## Контекст

Коллекция устанавливалась из ссылки на исходный репозиторий. Пользователю
приходилось передавать одновременно адрес репозитория, диапазон версии и цель
установки. APM поддерживает реестры пакетов: один репозиторий публикует каталог,
а проекты-потребители подключают его и устанавливают пакет по устойчивому имени.

Владелец проекта поручил перевести публикацию коллекции на реестр APM по модели
`ai-russian-language`. Изменение затрагивает способ обнаружения и установки
коллекции, но не состав публикуемых навыков.

## Рассмотренные варианты

### 1. Сохранить установку напрямую из репозитория

Вариант не требует метаданных реестра, но оставляет пользователю составление
ссылки на репозиторий и диапазона версии.

### 2. Опубликовать собственный реестр APM в этом репозитории

Вариант добавляет один раздел `marketplace` в манифест, генерируемые описания
для Claude и Codex и устойчивое имя пакета. Потребитель один раз подключает
реестр, после чего устанавливает и обновляет коллекцию обычными командами APM.

## Решение

Принят вариант 2. Репозиторий публикует реестр и пакет с именем
`ai-agent-supervisor`. Реестр собирается по тегу, совпадающему с версией
пакета. Для Claude и Codex в репозитории хранятся сгенерированные описания
реестра.

## Последствия

- Установка начинается с `apm marketplace add mekras/ai-agent-supervisor`.
- Пакет устанавливается по имени `ai-agent-supervisor@ai-agent-supervisor`.
- Перед выпуском необходимо проверить записи реестра и сгенерировать его
  описания командой `apm pack`.
- Создание тега и публикация в удалённом репозитории остаются действиями
  владельца выпуска.

## Проверка и условия пересмотра

Проверка включает `apm marketplace check`, сборку реестра командой `apm pack`,
проверку отсутствия дрейфа с `apm pack --check-clean --dry-run` и обычный
детерминированный набор `apm run tests`.

Решение следует пересмотреть, если APM изменит формат реестра, прекратит
поддержку выходов для Claude или Codex либо появится обязательный для целевой
аудитории другой способ распространения.

## История
