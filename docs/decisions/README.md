# Журнал решений

В этом каталоге хранятся записи значимых решений проекта. Новую запись создают,
когда решение задаёт устойчивое правило, имеет долгие последствия или требует
заметных затрат на отмену.

## Правила журнала

- Все записи используют один журнал без разделения по видам решений.
- Имя файла: `DR-NNNN.md`, где `NNNN` — четырёхзначный номер.
- В записи указывают контекст, рассмотренные варианты, принятое решение,
  последствия и способ проверки.
- Запись описывает само решение. Статусы, даты принятия, история согласований,
  ход реализации и результаты выполненных проверок в неё не включаются.

## Реестр

Записи расположены в порядке чтения: от общих оснований к частным решениям.
Номера служат устойчивыми идентификаторами и не задают порядок чтения.
