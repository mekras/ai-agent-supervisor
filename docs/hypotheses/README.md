# Реестр гипотез

Каждая гипотеза хранится в отдельном файле со стабильным идентификатором. Индекс
содержит только краткие метаданные и ссылки. Ход проверки и свидетельства
хранятся в записи гипотезы.

- **Гипотеза:** [HYP-0001](HYP-0001.md) **Название:** Последовательный выбор
  моделей подагентов **Статус:** Недостаточно данных **Последняя проверка:**
  2026-08-12 **Связанные решения:** [DR-0004](../decisions/DR-0004.md)
