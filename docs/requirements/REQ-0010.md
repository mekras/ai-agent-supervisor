# REQ-0010: Явные зависимости поставляемых скриптов

- **Статус требования:** принято 2026-08-05
- **Состояние реализации:** выполнено
- **Уровень:** ограничение продукта
- **Источник:** решение владельца проекта от 2026-08-05
- **Приоритет:** обязательное

## Требование

Поставляемый скрипт должен использовать только стандартную библиотеку своего
объявленного интерпретатора. Импорт стороннего пакета запрещён по умолчанию.

Исключение допустимо только для специализированного P1 или P2, если зависимость
нельзя разумно исключить. Тогда навык должен объявить пакет и совместимую
версию, способ воспроизводимой установки, источник, лицензию, сетевое поведение
и безопасный отказ. Такой скрипт не может быть единственным путём к основному
результату общего навыка.

## Критерии приёмки

1. Python-скрипты публикуемой коллекции проходят статическую проверку импортов
   относительно стандартной библиотеки.
2. Новый сторонний импорт блокирует обязательную проверку до явного оформления
   исключения и решения владельца.
3. В обязательном маршруте нет скрытых `pip install`, `uv run`, `npx` и иных
   действий, способных скачать или установить код.
4. Отсутствие стороннего пакета не приводит к необработанному исключению и не
   уничтожает доступный P0.

## История изменений

- 2026-08-05 — принято и реализовано. Поставляемые Python-скрипты переведены на
  стандартную библиотеку либо исключены из обязательного маршрута.
