# REQ-0019. Полнота доставки оснастки при настройке коллекции

## Требование

При первичной и повторной настройке публикуемой коллекции продукт должен
подтверждать полноту доставки поставляемой оснастки в целевой проект.
Установка или обновление навыков, успешный аудит APM и существующие тесты
не являются достаточным свидетельством доставки рабочих копий.

## Критерии приёмки

1. Сверка охватывает все назначения комплекта из манифеста используемого
   навыка независимо от того, откуда проект запускает существующие проверки.
2. После обновления навыка отсутствующий аудитор в `tools/` обнаруживается,
   доставляется в разрешённой области и совпадает с поставляемым источником.
3. Неполный комплект, несовпадение или невыполненная обязательная проверка
   не позволяют объявить шаг настройки завершённым.
4. Собственный файл целевого проекта не перезаписывается поставляемой копией
   без разрешения на разрешение конфликта.
5. Обычный проект-потребитель без публикации коллекции не получает комплект
   только из-за обновления зависимости.

## Источник и статус

- Источник: предложение исправить пропуск доставки при повторной настройке,
  согласованное владельцем 2026-10-08 командой «Делай».
- Уровень: требование к результату настройки.
- Статус: принято.
- Реализация: в работе. Процедура и регрессии подготовлены, выполнение новой
  процедуры моделью ещё не проверено.
