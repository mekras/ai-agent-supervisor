# REQ-0007: Базовый переносимый маршрут навыка

- **Статус требования:** принято 2026-08-05
- **Состояние реализации:** выполнено
- **Уровень:** атрибут качества продукта
- **Источник:** решение владельца проекта от 2026-08-05
- **Приоритет:** обязательное

## Определения

**Базовый маршрут P0** — полезный основной результат навыка, который агент
может получить по инструкциям и возможностям целевой задачи без запуска
поставляемого скрипта, установки интерпретатора, загрузки пакета или наличия
POSIX-оболочки.

**Автоматизированный маршрут P1** — необязательное ускорение или проверка,
которым нужен явно объявленный переносимый интерпретатор или исполняемый файл.

**Платформенный маршрут P2** — необязательное действие, привязанное к явно
названной операционной системе, оболочке или оснастке.

## Требование

Каждый навык общего назначения должен иметь базовый маршрут P0. Отсутствие
Python, Node.js, POSIX-оболочки, сети или возможности установить пакет не должно
лишать пользователя всего полезного результата навыка.

Навык без P0 допустим только тогда, когда его предмет по своей природе зависит
от конкретной платформы или исполняемой среды. Такое ограничение должно быть
явно указано в поле `compatibility` и в процедуре навыка. Навык нельзя объявлять
переносимым за пределами этой среды.

## Критерии приёмки

1. У навыка со скриптами описан P0 либо обосновано обязательное ограничение
   среды.
2. P0 не требует запуска файла из `scripts/**`, установки пакета или доступа к
   сети.
3. Инструкция различает P0, P1 и P2 и не выдаёт платформенный маршрут за общий.
4. Проверка коллекции отклоняет новый навык со скриптами без объявления
   совместимости и базового маршрута.
5. Сценарий результата проверяет случай, когда Python и POSIX-оболочка
   недоступны.
6. Каждый публичный Python-скрипт P1 первого уровня в `scripts/` имеет
   исполнимый контракт с реалистичной фикстурой. Контракт запускает
   поставляемую команду и проверяет внешний результат. Для сохранённого JSON
   проверка повторно читает созданный файл.
7. Контроль качества публикуемой коллекции отклоняет `__pycache__`, `.pyc` и
   `.pyo` в исходном дереве `.apm`.
