# REQ-0015. Условия запуска обучения на опыте

## Требование

У пользователя должна быть возможность запускать обучение вручную и включать
автоматический запуск. По умолчанию обучение запускается вручную для текущего
проекта, пользователь может выбрать другую доступную область.

Во включённом режиме текущий агент перед итоговым ответом должен разбирать
новый опыт: повторяемый способ работы, решение ошибки, поправку пользователя
или недостаток навыка. Неизменившиеся наблюдения,
отклонённые предложения и записи самого обучения не должны вызывать повторный
разбор без новых оснований или запроса пользователя.

## Критерии приёмки

1. Ручной запуск работает по переданным материалам или доступной истории
   без внешней интеграции согласно [REQ-0007](REQ-0007.md).
2. Автоматический запуск можно включить и выключить. Во включённом режиме
   каждый перечисленный вид нового опыта вызывает разбор текущим агентом до
   итогового ответа.
3. Повторное получение прежних сведений не запускает обучение заново.
   При недоступности сохранения пользователь видит ограничение и сохраняет
   возможность разового разбора.
