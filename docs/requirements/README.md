# Требования проекта

В этом каталоге хранятся принятые и предлагаемые требования к публикуемому продукту проекта — коллекции навыков.

## Правила ведения

- Каждое требование должно записываться отдельно и получать устойчивый идентификатор `REQ-NNNN`.
- Имя файла должно совпадать с идентификатором требования: `REQ-NNNN.md`.
- Запись должна содержать формулировку и проверяемые критерии приёмки.
