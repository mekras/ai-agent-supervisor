# REQ-0013. Структурное улучшение навыков по опыту

## Требование

Продукт должен использовать опыт работы для создания, обновления и
реструктуризации навыков. Реструктуризация должна поддерживать разделение,
объединение, удаление навыков, перенос правил и связанных материалов между
ними, а также комбинации этих изменений.

Изменения должны иметь основание в опыте работы и охватывать связанные навыки.
При недостаточных основаниях продукт должен сохранять наблюдение без изменения
навыков. Результаты последующего применения должны позволять оценить пользу
изменения, включая повторные ошибки.

## Критерии приёмки

1. Поддерживаются все перечисленные преобразования и их комбинация для
   нескольких связанных навыков.
2. Для изменения доступно исходное наблюдение. Неподтверждённый результат
   не становится основанием автоматического изменения.
3. Последующие успешные и неуспешные применения связаны с изменёнными навыками.
