# REQ-0018. Граница вывода о ненужности артефакта

## Источник

Поручение пользователя от 2026-09-16 по разбору наблюдаемого провала: агент
рекомендовал перестать отслеживать в Git сгенерированные файлы настроек
внешнего инструмента, опираясь только на отсутствие читающего их кода внутри
репозитория.

## Уровень

Свойство результата публикуемой коллекции навыков.

## Статус требования

Статус: **принято** (2026-09-16).

## Состояние реализации

Состояние: **в работе**. Процедура, барьер и модельные сценарии добавлены;
снижение частоты ошибки в реальных задачах пока не наблюдалось.

## Требование

Продукт не должен допускать вывод о ненужности артефакта, основанный только на
отсутствии его потребителя внутри репозитория.

Перед рекомендацией удалить артефакт, перестать отслеживать его в Git, внести в
список исключений, перестать публиковать или устанавливать агент должен
установить владельца и все классы возможных потребителей, жизненный цикл
артефакта и, для изменяемого поведения внешнего потребителя, подтверждение по
актуальному авторитетному источнику. Без подтверждения вывод остаётся условным.

Требование соразмерно: для файла без признаков внешнего назначения, все
потребители которого найдены в репозитории, достаточно зафиксировать
проверенный список потребителей.

## Критерии приёмки

1. На запросе о судьбе сгенерированного файла в каталоге настроек внешнего
   инструмента результат называет этот инструмент возможным потребителем и не
   выдаёт поиск по репозиторию за исчерпывающую проверку.
2. Результат различает порядок «клонирование, установка, запуск инструмента» и
   порядок «клонирование, запуск инструмента, установка внутри его сеанса» и
   связывает с ними разную цену отсутствия артефакта в свежем клоне.
3. Неподтверждённое поведение внешнего потребителя не превращается в
   безусловную рекомендацию: названы неизвестное, варианты с условием выбора и
   конкретное недостающее свидетельство.
4. Сведения из изменяемой документации внешнего инструмента сопровождаются
   версией или датой проверки и не подаются как вечное правило.
5. Для обычного внутреннего файла требование не приводит к обязательному
   внешнему исследованию.
