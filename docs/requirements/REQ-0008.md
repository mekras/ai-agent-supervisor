- **Приоритет:** обязательное

## Требование

До запуска необязательной автоматизации навык должен проверить требуемый
интерпретатор, команды, пакеты, сеть и платформу. Если зависимость недоступна,
навык должен перейти на документированный базовый маршрут либо остановить
только зависящую от неё часть работы.

Результат должен различать три состояния:

- действие выполнено и автоматически проверено
- действие выполнено без автоматической проверки
- действие невозможно из-за обязательной зависимости

Навык не должен молча устанавливать интерпретатор или пакет, обращаться к сети
либо считать отсутствие необязательного скрипта провалом всей задачи.

## Критерии приёмки

1. Для каждого P1 и P2 указан предварительный контроль зависимостей.
2. При отсутствии необязательной зависимости процедура продолжает P0 и явно
   сообщает, какая автоматическая проверка не выполнена.
3. Автоматическая установка и сетевое получение зависимости требуют отдельного
   явного решения пользователя или проекта.
4. Сообщение об ограничении называет недостающую зависимость, затронутую часть
   результата и доступный следующий путь.
