# REQ-0009: Переносимые команды и пути

- **Статус требования:** принято 2026-08-05
- **Состояние реализации:** выполнено
- **Уровень:** ограничение продукта
- **Источник:** решение владельца проекта от 2026-08-05
- **Приоритет:** обязательное

## Требование

Обязательный переносимый маршрут не должен зависеть от синтаксиса одной
командной оболочки или способа запуска интерпретатора в одной операционной
системе.

В P0 запрещены, в частности, `sh -c`, `$VAR`, `${...}`, `$(...)`, конвейеры и
перенаправления оболочки, цепочки `&&`, `/dev/null`, `chmod`, `mktemp`, запуск
только через shebang, жёстко заданный `python3` и ручное соединение путей
разделителем конкретной системы.

Эти конструкции допустимы в P2, а вызов интерпретатора допустим в P1, если
класс маршрута, среда и альтернатива описаны явно. Примеры команд должны либо
быть платформенно нейтральными, либо иметь варианты для всех заявленных сред.

## Критерии приёмки

1. Общие инструкции не требуют POSIX-команд для получения P0.
2. Платформенные команды помечены как P2 и не являются единственным путём к
   основному результату общего навыка.
3. Пути в переносимых скриптах строятся средствами языка, а не ручным
   разделителем платформы.
4. Детерминированный валидатор выявляет обязательные POSIX-команды и жёстко
   заданный запуск Python в проверяемых инструкциях.
