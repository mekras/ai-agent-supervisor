# REQ-0055. Достоверность пользовательских описаний продукта

Численные обещания, безусловные гарантии и заявления о выполненных проверках
в пользовательском описании продукта должны опираться на свидетельства.
Описание может кратко сообщать о пользе продукта и его обычной работе после
настройки. Существенные для читателя условия должны быть видны.

Статус — **Принято**. Требование выделено из REQ-0039.7 по согласованию
23 ноября 2026 года.

## Критерии приёмки

- Краткое описание обычной пользы после настройки содержит существенные
  условия. Для замечания нужны основания помимо отсутствия измерений
  или оговорок.
- Численное обещание, безусловная гарантия или заявление о выполненной
  проверке подтверждены для описанных условий. Агент сопоставляет весь
  фрагмент с фактами и учитывает условия настройки.
  Замечание о чрезмерной уверенности называет ошибочный вывод читателя
  и его существенные последствия.
