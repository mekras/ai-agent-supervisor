# REQ-0050. Сохранность правил при выносе из инструкций агента

## Статус и источник

Требование **принято** владельцем проекта 2026-11-19 ответом «Делай»
на предложение дополнить навык сопровождения `AGENTS.md` по опыту
сокращения `AGENTS.md` этого проекта. Классификация —
`specification_change` по
[порядку изменений](../decisions/DR-0010.md#порядок-изменений).

Основание — правка, которой процедуры работы с APM и выпуска версии вынесены
из `AGENTS.md` проекта в справочные документы[^move]. Вынесенный блок APM
содержал два правила, нужных и при обычной правке навыков: запрет явной
компиляции Python и указание, что правка исходников навыков не требует
установки. Агент оставил их в `AGENTS.md` по собственному суждению, чек-лист
навыка этого не требовал. Чек-лист не требовал и проверить, что при переносе
не потерялось ни одно правило. Сохранность агент проверил сам, сопоставив
предложения прежнего файла с новыми.

Цель — пользователь целевого проекта сокращает инструкции агента выносом
редких процедур и не теряет правила, которые действовали до сокращения. Это поддерживает [назначение коллекции](../concept.md):
подготовку правил работы агента выполняет агент, а необходимые знания
доступны в нужный момент.

## Требование

Когда агент выносит правила из `AGENTS.md` или соседнего файла инструкций
во вложенный файл или навык, навык сопровождения
`AGENTS.md` ведёт его сохранить действие каждого вынесенного правила.

### REQ-0050.1. Правила вне вынесенной процедуры

Правило, которое нужно агенту вне вынесенной процедуры, например запрет,
действующий и при обычной правке, остаётся в исходном файле.

### REQ-0050.2. Момент срабатывания условия чтения

Условие чтения вынесенного материала срабатывает до действия, которое этот
материал регулирует. Если материал заменяет или уточняет инструкцию навыка
либо команды, условие срабатывает до их вызова.

### REQ-0050.3. Проверка сохранности переноса

После переноса агент проверяет, что каждое правило прежнего текста нашлось
в новом месте. Изменённые и удалённые правила результат называет вместе
с причиной. Новые места перенесённых правил результат называет по группам.
Сопоставление каждого правила с его новым местом остаётся в истории работы
и выдаётся по запросу.

## Критерии приёмки

1. **Общий запрет остаётся в корне** (REQ-0050.1). Пользователь просит
   вынести из `AGENTS.md` процедуру выпуска, внутри которой есть запрет менять
   номер версии вне выпуска. Процедура перенесена в навык, а запрет остался
   в `AGENTS.md`.
2. **Условие до регулируемого действия** (REQ-0050.2). Условие чтения
   вынесенной процедуры выпуска срабатывает до первого выпускного действия.
   Процедура заменяет шаг навыка выпуска, поэтому условие срабатывает и до вызова этого навыка.
3. **Нет потери при переносе** (REQ-0050.3). Агент сопоставил каждое
   правило прежнего текста с новым местом. Результат называет изменённые
   и удалённые правила с причиной и новые места перенесённых правил
   по группам. По запросу агент выдаёт место каждого правила. Правило,
   пропавшее без объяснения, означает провал.

## Связи и трассировка

Требование дополняет [REQ-0033](REQ-0033.md) о сопровождении инструкций
и сохраняет [управление сложностью](REQ-0020.md): правила действуют только
при выносе, не требуют отдельного средства проверки и не увеличивают
постоянно читаемый текст навыка.

## Реализация и состояние проверки

Правила реализованы в разделах «Отбери содержание по пользе для агента»
и «Проверь иерархию и конфликты»
[чек-листа сопровождения](../../.apm/skills/ai-agents-md-maintenance/references/maintenance-checklist.md),
в шаге 12 и разделе «Формат результата»
[навыка ai-agents-md-maintenance](../../.apm/skills/ai-agents-md-maintenance/SKILL.md).
Критериям 1 и 2 соответствует сценарий
`ai-agents-md-maintenance-result-move-keeps-general-rules`, критерию 3 —
сценарии `ai-agents-md-maintenance-result-move-reports-every-rule`
и `ai-agents-md-maintenance-result-move-rule-map-on-request`
в [проверочных случаях](../../.apm/skills/ai-agents-md-maintenance/evals/result-scenarios.json).

Структурные проверки сценариев не подтверждают исполнение правила моделью.
Модельный прогон сценариев не выполнялся.

## История изменений

- 2026-11-19 — записано принятое требование и критерии его проверки.
- 2026-11-20 — по решению владельца справка и документ исключены из мест
  выноса: инструкции для агентов остаются в файлах инструкций для агентов.
- 2026-11-20 — по решению владельца («Согласен» на предложение по итогам
  сверки навыков с правилами общения, `specification_change`) результат
  называет новые места правил по группам, а место каждого правила выдаёт
  по запросу. Прежняя редакция переносила в ответ построчную карту
  и противоречила отбору сведений для человека по [REQ-0052](REQ-0052.md).
