# REQ-0033. Сохранение области и доставки инструкций при сопровождении

При сопровождении инструкций правила должны сохранять область действия
и оставаться доступными через действующие точки входа. Решения пользователя
должны сохраняться.

До правки должны быть установлены действующие точки входа и область каждого
изменяемого правила. Конфликты между уровнями инструкций должны быть видны.
Локальное правило не должно отменять общее без явного указания.
Общие правила не должны дублироваться в точках входа разных оснасток, если
подтверждён способ обращения к одному источнику. Ссылки и доставка правил
должны быть проверены.

## Вынос правил из инструкций

Правила из `AGENTS.md` или соседнего файла при выносе должны оставаться
в инструкциях для агента — во вложенном файле инструкций или навыке.

- Правила, нужные вне вынесенной процедуры, должны оставаться в исходном файле.
- Условие чтения должно срабатывать до регулируемого действия. Если вынесенный
  текст заменяет или уточняет инструкцию навыка либо команды, условие должно
  срабатывать до их вызова.
- После переноса все прежние правила должны быть сверены с итоговым текстом.
  В результате должны быть названы изменённые и удалённые правила с причинами
  и новые места перенесённых правил по группам. Место каждого перенесённого
  правила должно быть доступно в истории работы и выдаваться по запросу.

## Критерии приёмки

1. До правки установлены точки входа и область каждого изменяемого правила.
2. Конфликт локального и общего правил указан явно. Скрытой отмены общего
   правила нет.
3. Ссылки и доставка общих правил проверены для действующих точек входа.
4. При выносе процедуры выпуска общий запрет менять номер версии вне выпуска
   сохраняется в исходном `AGENTS.md`.
5. Условие чтения вынесенной процедуры выпуска срабатывает до первого
   регулируемого действия и до вызова навыка, шаг которого она заменяет.
6. Все прежние правила учтены. Изменения и удаления объяснены, новые места
   указаны по группам. По запросу названо место каждого перенесённого правила.
   Пропуск правила без объяснения означает провал проверки.
