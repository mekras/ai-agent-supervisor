# Проверка результата анализа моделей

Дата: 2026-10-04.

Проверена текущая версия навыка в трёх последовательных сеансах Codex CLI:
`gpt-5.6-luna`, усилие `high`, через подписку ChatGPT. Автоматических повторов
не было. Входы учебные, инструменты сеансов без сети, реальные настройки
подагентов не изменялись. Сеансы получали только запрос и разрешённые входы,
без критериев ожидаемого ответа. Результаты оценены родительским агентом
по содержанию файлов и журналам, отдельная модель-судья не запускалась.

## Результаты

| Проверка | Наблюдаемый результат |
| --- | --- |
| `ai-model-analysis-result-comparable-measurements` | Сохранены обе принятые пары, полные затраты 3 и 4 USD с учётом исправления, время полного пути и участия человека разделены. Неизмеренная пара и ограничения единичного наблюдения сохранены. |
| `ai-model-analysis-result-all-study-participants` | Извлечены 15/20, 18/20 и 17/20 для трёх пар. Результат 16/20 с неизвестным усилием сохранён на уровне модели. Участник вне каталога не добавлен, отсутствие кода стенда не обнулило измерения. |
| Потребитель готового профиля | Отдельный сеанс получил только профиль первой проверки и новую задачу выбора. Выбрал `model-a/high` для тех же условий по полной стоимости 3 против 4 USD, сохранил ограничения качества и единственной попытки. Реальная конфигурация не менялась. |

Вход потребителя побайтно совпал с сохранённым профилем первого сеанса.
Исходный набор измерений, навык анализа и ожидаемый выбор потребителю
не передавались. Код завершения всех сеансов — 0, зарегистрированных ошибок
инструментов нет. В двух сценариях навыка изменены только учебные файлы целей
и анализа.

## Воспроизведение проверки передачи

Сначала выполни сценарий `ai-model-analysis-result-comparable-measurements`
на актуальном навыке. Передай полученный профиль новому сеансу без исходных
измерений и контекста первого запуска. Попроси выбрать пару для следующей
учебной задачи того же вида и условий, с допустимыми небольшими исправлениями,
приоритетом меньших полных затрат в USD и без приоритета времени.
Потребитель должен назвать пару либо конкретный пробел, привести основания
из профиля и ограничения переноса. Изменение реальной конфигурации запрещено.

Проверяй основание выбора, не одно совпадение названия модели. Полная стоимость
не должна превращаться в API-стоимость или расход подписки. Неизмеренная пара
не должна получить выдуманное качество. Единственная попытка не доказывает
универсального превосходства.

## Границы свидетельства

Проверка подтверждает извлечение предоставленных данных и возможность
предварительного выбора подагента из полученного профиля в учебной задаче.
Она не доказывает полноту интернет-поиска, экономию реальной подписки, качество
реальных моделей или преимущество навыка над работой без него.
Все 25 сценариев моделью не запускались.
Недостаток первичных данных нельзя исправлять выдуманными характеристиками.

Журналы, запросы, снимки входов и результатов сохранены локально в
`.git/model-analysis-behavior-20261004/`. Этот каталог не является частью
публикуемого навыка. Токены журналов не переведены в расход лимита подписки.
