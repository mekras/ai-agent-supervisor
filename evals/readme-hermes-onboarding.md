# Проверка подключения коллекции в Hermes по README

## Предмет и границы

Аналитическая проверка [инструкции подключения](../README.md#установка)
глазами [Ольги](../docs/Персонажи/Ольга.md): она уже общается с Hermes,
программированием не занимается и хочет использовать его как личного помощника.
Наличие APM или подготовленного Git-репозитория заранее не предполагается.

Проверяется понятность пути от просьбы установить коллекцию до обнаружения
и открытия навыка настройки. Этот случай не запускает установку, модели или
навыки. Проход по тексту не подтверждает работоспособность среды и не заменяет
живое испытание установки.

## Основной путь

1. Ольга находит в README запрос для передачи в существующий диалог Hermes.
   Для первого шага ей не нужно самостоятельно выполнять команды в терминале.
2. Запрос однозначно задаёт коллекцию, версию и установку в профиль Hermes.
   Установку выполняет агент. Она не подменена установкой только в проект.
3. Перед настройкой агенту поручена проверка как обнаружения, так и открытия
   `ai-setup-project`. Сообщения установщика об успехе для этого недостаточно.
4. После проверки доступности Ольга находит отдельный запрос
   `Выполни ai-setup-project` и пример с контекстом личного помощника.
5. Текст не обещает, что установка сама по себе завершает настройку или
   подтверждает готовность помощника ко всем поручениям.

## Проверка отклонений

| Ситуация | Что должно быть понятно из README |
| --- | --- |
| APM скачал зависимость, но пропустил развёртывание навыков | Переход к настройке зависит от обнаружения и открытия навыка, а не только от успеха команды установки |
| Навык есть в списке, но агент не может его открыть | Проверка открытия остаётся обязательной частью запроса, проблема не объявляется устранённой по одному списку |
| Часть проверок установки не прошла | Агенту поручено сообщить ограничения, полная готовность не обещана |
| Выбрана установка в конкретный проект | Этот вариант отделён от установки в профиль, указаны корень Git-репозитория, доверие и проверка доступности |
| После проектной установки навык недоступен | Есть выполнимое действие: передать агенту вывод команд и каталог запуска до перехода к настройке |
| Навыки установлены в профиль Hermes | Доверие проекту не навязано как общий шаг подключения |
| Навыки добавлены в существующем диалоге | Новый диалог или перезапуск не объявлены универсальным условием успеха |

## Оценка

При проходе укажите проверенную версию README и для каждого пункта основного
пути и отклонения приведите относящийся к нему фрагмент текста. Отметьте
препятствия и неизвестное. Проход считается успешным в области понятности
инструкции, если все пункты покрыты и существенных препятствий для Ольги нет.
Успех аналитической проверки не является свидетельством выполнения команд,
загрузки навыка в конкретном Hermes или завершения настройки.
