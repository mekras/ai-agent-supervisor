# Проверка подключения и настройки личного помощника Hermes

## Предмет и границы

Аналитическая проверка пути из [README](../README.md#установка)
в [руководство подключения и настройки Hermes](../docs/hermes.md)
глазами [Ольги](../docs/Персонажи/Ольга.md): она уже общается с Hermes,
программированием не занимается и хочет использовать его как личного помощника.
Наличие APM или подготовленного Git-репозитория заранее не предполагается.

Проверяется понятность пути от просьбы установить коллекцию до настройки
выбранного профиля и проверки загрузки инструкций в новом разговоре. Этот случай не запускает установку, модели или
навыки. Проход по тексту не подтверждает работоспособность среды и не заменяет
живое испытание установки.

## Основной путь

1. Ольга переходит из README в руководство и находит запрос для передачи в существующий диалог Hermes.
   Для первого шага ей не нужно самостоятельно выполнять команды в терминале.
2. Запрос однозначно задаёт коллекцию, версию и установку в профиль Hermes.
   Установку выполняет агент. Она не подменена установкой только в проект.
3. Перед настройкой агенту поручена проверка как обнаружения, так и открытия
   `ai-setup-project`. Сообщения установщика об успехе для этого недостаточно.
4. После проверки доступности Ольга находит запрос личной настройки без
   готового проекта. Понятно, что выбирается фактический каталог профиля,
   переходить в него или создавать Git-репозиторий не требуется.
5. Общие инструкции выбранного профиля отделены от правил рабочего каталога.
   До подтверждения изменений понятны файлы, область действия и последствия
   для доступа к данным и расходов.
6. После сохранения Ольга находит действие проверки в новом разговоре того же
   профиля. Наличие файла и отчёт о сохранении не подменяют загрузку инструкций.
7. Текст не обещает, что установка сама по себе завершает настройку или
   подтверждает готовность помощника ко всем поручениям.

## Проверка отклонений

| Ситуация | Что должно быть понятно из руководства |
| --- | --- |
| APM скачал зависимость, но пропустил развёртывание навыков | Переход к настройке зависит от обнаружения и открытия навыка, а не только от успеха команды установки |
| Навык есть в списке, но агент не может его открыть | Проверка открытия остаётся обязательной частью запроса, проблема не объявляется устранённой по одному списку |
| Часть проверок установки не прошла | Агенту поручено сообщить ограничения, полная готовность не обещана |
| Выбрана установка в конкретный проект | Этот вариант отделён от установки в профиль, указаны корень Git-репозитория, доверие и проверка доступности |
| После проектной установки навык недоступен | Есть выполнимое действие: передать агенту вывод команд и каталог запуска до перехода к настройке |
| Навыки установлены в профиль Hermes | Доверие проекту не навязано как общий шаг подключения |
| Навыки добавлены в существующем диалоге | Обнаружение и открытие навыка проверяются до настройки, новый разговор нужен отдельно для проверки изменённых инструкций профиля |
| Проекта заранее нет | Личная настройка продолжается в выбранном профиле, без создания проекта и доверия каталогу |
| Активен именованный профиль | Путь определяется по текущему профилю, расположение по умолчанию не подставляется автоматически |
| Нет канала одобрения защищённой записи | Подготовленная правка передаётся пользователю для самостоятельного применения, обход защиты не предлагается |
| Инструкции сохранены, но новый разговор не проверен | Настройка остаётся непроверенной в части загрузки, дан запрос для завершения проверки |

## Оценка

При проходе укажите проверенные версии README и руководства и для каждого пункта основного
пути и отклонения приведите относящийся к нему фрагмент текста. Отметьте
препятствия и неизвестное. Проход считается успешным в области понятности
инструкции, если все пункты покрыты и существенных препятствий для Ольги нет.
Успех аналитической проверки не является свидетельством выполнения команд,
загрузки навыка в конкретном Hermes или завершения настройки.

Критерии личного пути закреплены в [требовании настройки профиля](../docs/requirements/REQ-0041.md).

Исполнение настройки и последующего обновления в проекте и личном профиле
проверяется отдельно по [сценарию полного цикла Hermes](compatibility/hermes-lifecycle.md).
