# Условия принятия отчёта о выпуске

Для выпуска обе обязательные проверки, `build` и `tests`, должны иметь статус
`PASS` в сохранённом отчёте запуска. Статус `FAIL` блокирует выпуск.
Исключения этой политикой не предусмотрены. Заявление исполнителя не заменяет
результат проверки. Этот документ задаёт правила только вымышленного проекта.
