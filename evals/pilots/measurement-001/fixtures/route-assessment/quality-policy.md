# Ограничение вымышленного проекта

Автоматическое применение экономичного маршрута допустимо только после
подтверждения сопоставимого качества с эталонным маршрутом для того же класса
задач по одинаковым критериям. Предполагаемая меньшая цена не заменяет такие
свидетельства. Анализ предложения сам по себе не разрешает менять конфигурацию.
